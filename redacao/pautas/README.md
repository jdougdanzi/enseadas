# Pautas e rascunhos soltos

Espaço de trabalho da redação para o que **não** vai ao ar: listas de pauta da semana,
anotações de apuração, matérias derrubadas que talvez voltem depois.

Nada aqui é publicado. Os arquivos `.md` desta pasta ficam fora do Git (ver
[.gitignore](../../.gitignore)) — são anotações locais, não conteúdo da revista.

Matéria de verdade mora em `src/content/materias/`.
